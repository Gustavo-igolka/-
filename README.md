# Minecraft Horror Project

> Ассиметричная хоррор-игра на Minecraft, вдохновлённая FNaF и другими играми жанра.

Этот репозиторий содержит Skript-код игрового режима: систему раундов, персонажей с уникальными способностями, карты, предметы, музыку и игровые механики.

Проект находится в разработке. Механики и состав персонажей могут изменяться.

---

## 🎮 О проекте

Игровой режим строится вокруг противостояния **одного убийцы и команды выживших**.

Участники выбирают предпочтительного персонажа, после чего система определяет роли и запускает раунд на выбранной карте. У каждого персонажа собственный набор предметов, способностей и особенностей.

Главная идея — не обычный PvP: убийцу нельзя просто победить уроном. Выжившим приходится использовать способности, взаимодействовать друг с другом и пытаться пережить раунд.

## ⚔️ Роли

### Убийцы

Убийца преследует выживших и использует специальные способности. В текущем наборе персонажей:

- **ДэнДэн**
- **Некромансик**
- **The Anomaly**
- **The Project**
- **Незрячий**

### Выжившие

Выжившие разделены на несколько игровых специализаций:

- **Рашеры** — мобильные персонажи, способные активно действовать и создавать давление на убийцу.
- **Стражи** — защищают команду и могут оглушать убийцу.
- **Поддержка** — помогают союзникам лечением и другими полезными эффектами.

Среди доступных персонажей: Андрей, Рататуй, Кирилл, Михуилонг, Илья, Маёр, МякШмяка, Томас, Саня и Dartikil.

## 🧩 Основные системы

- **Выбор персонажа.** Отдельные меню предпочтений для убийцы и выжившего.
- **Уникальные наборы.** При старте раунда персонаж получает собственные предметы и параметры.
- **Способности и перезарядка.** Активные навыки, эффекты, ограничения и индивидуальные механики персонажей.
- **Система раундов.** Запуск, завершение и подготовка следующего матча.
- **Карты и точки появления.** Для каждой карты настраиваются спавны убийцы, выживших и дополнительных предметов.
- **Случайный выбор карты.** Карты выбираются без повторов, пока не будет пройден весь доступный набор.
- **Музыка и звуковое оформление.** Отдельная музыка лобби, фоновые звуки карт и музыка погони.
- **Предметы на карте.** Например, аптечки и предметы скорости.
- **Игровые события и тестирование.** Дополнительные режимы и инструменты для настройки механик.

## 🗺️ Настройка карт

Основные команды настройки доступны операторам:

| Команда | Назначение |
| --- | --- |
| `/addmap <имя>` | Добавить карту |
| `/listmaps` | Посмотреть список карт |
| `/checkround <имя>` | Проверить готовность карты |
| `/setmaniacspawn <имя>` | Установить точку убийцы |
| `/setsurvivorspawn <имя>` | Добавить точку появления выжившего |
| `/setitemspawn <имя>` | Добавить точку появления предметов |
| `/setambient <имя> <звук> <секунды>` | Настроить фоновый звук карты |
| `/setchasemusic <персонаж> <звук> <секунды>` | Настроить музыку погони |

Также предусмотрены команды настройки лобби и комнат ожидания:

- `/setlobby`
- `/setwaitmaniac`
- `/setwaitsurvivor`

После настройки карты можно запустить раунд командой `/startround <имя>`. Для выбора случайной карты используется `/startround random`.

## 📁 Структура проекта

Основные Skript-файлы:

| Файл | Назначение |
| --- | --- |
| `characters.sk` | Персонажи, меню выбора и стартовые наборы |
| `abilities.sk` | Способности персонажей и система перезарядки |
| `blind.sk` | Механики и способности Незрячего |
| `round.sk` | Логика раундов, погоня и выбор карт |
| `setup.sk` | Настройка мира, карт и точек появления |

В репозитории также находятся вспомогательные скрипты для отдельных игровых систем.

## 🛠️ Технологии

- Minecraft Java Edition
- Skript

Некоторые команды и настройки в коде ориентированы на Minecraft **1.19.4**. Совместимость с другими версиями и сборками сервера следует проверять отдельно.
